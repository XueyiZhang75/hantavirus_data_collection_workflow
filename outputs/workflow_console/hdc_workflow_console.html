8. Workflow run sequence

操作流程

  1. Open or generate a runtime profile for the intended disease, location, and time window.
  2. Submit the task request shown in this session's task panel.
  3. 启动 Studio：python scripts/start_hdc_workflow_studio.py
  4. 查看 workflow 节点顺序：主流程是串行 state pipeline，quality_gate_routing 是关键条件分支。
  5. 同配置导出可读报告和本页 console：python scripts/run_hdc_workflow_configured.py
  6. Open the dataset views and diagnostics listed above.

现场说明

This view separates technical completion from accepted data success. A run can complete while producing zero accepted quality-gated records, and that status is shown explicitly above.

Regenerate this console after each run so status, counts, validation compatibility, and artifact links match the selected session.
